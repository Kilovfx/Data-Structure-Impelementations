# Data Structure Implementations

A C++ project that demonstrates the implementation and use of common **data structures and algorithms** through a simple country management system.

## Features

* Add and delete countries
* Search countries by name and coordinates
* Binary search
* Quick Sort by:

  * Country name
  * Population
* Find the distance between countries
* Find the nearest countries
* Display all countries
* Save country data to a file
* Basic input validation and error handling

## Data Stored

Each country contains:

* Name
* X coordinate
* Y coordinate
* Population

## Technologies

* C++
* STL `vector`
* File I/O
* Sorting and searching algorithms

The project was created to practice **data structures, searching, sorting, file handling, and algorithm implementation in C++**.
